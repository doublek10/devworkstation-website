What's inside

Every module below ships in the same install and reads from the same local database. Open the ones you need this week; the rest stay out of the way.

§01

CV builder

Write, style, and export a resume as a finished PDF — typeset locally, no template site required.

§02

PDF studio

Inspect, split, merge, rotate, and pull text out of PDFs without uploading them anywhere.

§03

Code editor

A syntax-highlighted editor with a file tree and tabs. Hit Run and it executes right there.

§04

Code analyzer

Point it at a folder and see the stack, routes, API calls, and import map in minutes.

§05

Test lab

Detects how a project is tested and runs it in a contained process — no surprise install scripts.

§06

Database lab

Inspect a SQLite file, get plain diagnoses, and back it up automatically before anything changes.

§07

Website lab

Check a site's headers, cookies, redirects, and DNS from one place.

§08

Server center

Keep server profiles and credentials together, with reachability at a glance.

§09

Terminal

A built-in shell that remembers your working directory and history between sessions.

§10

Files

Browse, edit, zip, and search a project's files without leaving the app.

§11

Vault

Credentials live in Windows Credential Manager — the app never stores them in plain text.

§12

Projects & logs

Every project registered once, every action logged and searchable afterward.

Getting started

Five short steps, about five minutes, done.

Step 1

Download

Click the download button above to get the installer.

Step 2

Install

Run it. If a blue "Windows protected your PC" screen appears, click "More info", then "Run anyway".

Step 3

Get your key

Click Get key, fill in the short form, and pay $10 via M-Pesa.

Step 4

Activate

Open the app, set a username and password, then enter the key you just bought.

Step 5

You're set

Click OK and you're in. After the first run, your login stays on this PC — you're fully in control.

Where your data actually lives

Not a policy promise — this is what the app does, module by module.

Your project data

Stored in a SQLite file under your own AppData folder. It never leaves your disk unless you export it yourself.

Your credentials

Passwords, API keys, and server logins are handed to Windows Credential Manager. DevWorkstation itself never returns a stored secret to its own screen.

Your accounts

There is no DevWorkstation account, no login server, and nothing to sync. Sign-in is local to this one installation.
